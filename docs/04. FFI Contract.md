# HỢP ĐỒNG GIAO TIẾP FFI C-ABI - SECURE VAULT MANAGER (SVM)

---

## 1. Nguyên Tắc Thiết Kế C-ABI & An Toàn Bộ Nhớ

1. **Ranh Giới Sở Hữu Bộ Nhớ Rõ Ràng (Ownership Contract):**
   - Mọi vùng nhớ do Rust cấp phát (`CString::into_raw` hoặc `Vec::into_raw_parts`) **phải** được giải phóng bởi Rust thông qua: `svm_free_string(char*)`, `svm_free_secret(char*)`, `svm_free_buffer(SvmBuffer)`. Phía C++ không gọi `free()` hay `delete` trực tiếp.
   - Các chuỗi bí mật giải mã (như đầu ra của `svm_item_reveal_field`, `svm_vault_get_recovery_key`, `svm_vault_rotate_recovery_key`, `svm_password_generate`) phải giải phóng bằng `svm_free_secret()` để zeroize vùng nhớ trước khi thu hồi.
2. **Quy Ước Xử Lý Lỗi (Error Handling):**
   - Mọi hàm trạng thái trả về `SvmStatusCode` (`typedef SvmStatusCode SvmStatus` hoặc enum số nguyên `int32_t`).
   - Thông báo lỗi chi tiết lưu trong Thread-Local Storage (`LAST_ERROR`) và đọc qua `svm_last_error()`.
3. **Bảo Vệ Panic (Panic Boundary):**
   - Các hàm C-ABI thao tác item trong `item_ffi.rs` (trừ `svm_item_delete`) và các hàm quản trị vault `svm_vault_rename`, `svm_vault_delete`, `svm_vault_set_default` trong `vault_ffi.rs` được bọc trong macro/helper `ffi_guard` sử dụng `std::panic::catch_unwind`, trả về `SVM_ERR_PANIC` (99) khi có panic.
4. **Cơ Chế Gọi Ngược Sự Kiện (Event Callbacks):**
   - `SvmEventCallback` có thể phát sinh từ các luồng nền của Rust (SSH Agent thread, Bridge IPC listener thread). Phía C++ Qt (`CoreBridge`) sử dụng `QMetaObject::invokeMethod(..., Qt::QueuedConnection)` để chuyển về luồng UI chính.
5. **Con Trỏ Tĩnh & Thread-Local:**
   - `svm_core_version()` trả về chuỗi tĩnh (`'static`), `svm_last_error()` trả về con trỏ TLS; C++ tuyệt đối không giải phóng 2 con trỏ này.
   - Các hàm có con trỏ đầu ra (`char **out_*`, `SvmBuffer *out`) cần được giải phóng chỉ khi hàm trả về `SVM_OK` và con trỏ khác `NULL` (`svm_qr_decode_rgba` và `svm_favicon_fetch` đảm bảo gán đầu ra về null/rỗng khi lỗi).

## 2. Định Nghĩa Kiểu Dữ Liệu Cơ Bản (`core/include/svm_core.h`)

```c
#ifndef SVM_CORE_H
#define SVM_CORE_H

#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

typedef struct SvmContext SvmContext;

typedef struct {
    uint8_t *ptr;
    size_t len;
} SvmBuffer;

typedef enum {
    SVM_OK                    = 0,
    SVM_ERR_INVALID_ARG       = 1,
    SVM_ERR_LOCKED            = 2,
    SVM_ERR_WRONG_PASSWORD    = 3,
    SVM_ERR_IO                = 4,
    SVM_ERR_CRYPTO            = 5,
    SVM_ERR_NOT_FOUND         = 6,
    SVM_ERR_PARSE             = 7,
    SVM_ERR_NETWORK           = 8,
    SVM_ERR_DENIED            = 9,
    SVM_ERR_TIMEOUT           = 10,
    SVM_ERR_CONFLICT          = 11,
    SVM_ERR_UNSUPPORTED       = 12,
    SVM_ERR_CANCELLED         = 13,
    SVM_ERR_PANIC             = 99
} SvmStatusCode;

typedef enum {
    SVM_EVENT_VAULT_LOCKED           = 1,
    SVM_EVENT_VAULT_UNLOCKED         = 2,
    SVM_EVENT_ITEMS_CHANGED          = 3,
    SVM_EVENT_PROMPT                 = 4,
    SVM_EVENT_PROMPT_CANCELLED       = 5,
    SVM_EVENT_IMPORT_PROGRESS        = 6,
    SVM_EVENT_BRIDGE_STATUS          = 7,
    SVM_EVENT_SSH_STATUS             = 8,
    SVM_EVENT_SHOW_WINDOW            = 9,
    SVM_EVENT_BRIDGE_CLIENTS_CHANGED = 10,
    SVM_EVENT_SETTINGS_CHANGED       = 11
} SvmEventKind;

typedef enum {
    SVM_FORMAT_SVM               = 1,
    SVM_FORMAT_BITWARDEN_JSON    = 2,
    SVM_FORMAT_1PUX              = 3,
    SVM_FORMAT_KEEPASS_XML       = 4,
    SVM_FORMAT_CSV               = 5
} SvmFormat;

typedef void (*SvmEventCallback)(int32_t kind, const char *payload_json, void *user_data);
```
