# HỢP ĐỒNG GIAO TIẾP FFI C-ABI - SECURE VAULT MANAGER (SVM)

---

## 1. Nguyên Tắc Thiết Kế C-ABI & An Toàn Bộ Nhớ

1. **Ranh Giới Sở Hữu Bộ Nhớ Rõ Ràng (Ownership Contract):**
   - Mọi vùng nhớ do Rust cấp phát (`malloc`/`Box::into_raw`/`CString::into_raw`) **phải** được giải phóng bởi Rust thông qua các hàm chuyên biệt: `svm_free_string`, `svm_free_secret`, `svm_free_buffer`. Phía C++ tuyệt đối không được gọi `free()` hoặc `delete` trực tiếp.
   - Vùng nhớ nhạy cảm chứa khóa mật mã hoặc dữ liệu giải mã **phải** được giải phóng bằng `svm_free_secret()` để thực hiện thao tác zeroize (ghi đè bằng số không) trước khi trả lại bộ nhớ cho hệ điều hành.
2. **Quy Ước Xử Lý Lỗi (Error Handling):**
   - Mọi hàm FFI trả về mã trạng thái `SvmStatus` (kiểu enum số nguyên 32-bit).
   - Chi tiết thông điệp lỗi được lưu trong biến vùng nhớ cục bộ của luồng (Thread-Local Storage) và truy xuất thông qua hàm `svm_last_error()`.
3. **Bảo Vệ Khỏi Lỗi Panic (Panic Boundary Guard):**
   - Toàn bộ thân hàm trong Rust C-ABI được bao bọc bởi macro `ffi_guard!`, sử dụng `std::panic::catch_unwind`. Nếu phát hiện Panic nội bộ, hàm lập tức ghi log và trả về mã lỗi `SVM_ERR_PANIC` (99), bảo đảm ứng dụng máy trạm C++ không bao giờ bị dừng đột ngột (crash/abort).
4. **Cơ Chế Gọi Ngược Sự Kiện (Event Callbacks):**
   - Callback con trỏ hàm `SvmEventCallback` có thể được gọi từ bất kỳ luồng chạy nền nào của Rust (ví dụ: tokio worker thread). Phía C++ Qt bắt buộc phải sử dụng `QMetaObject::invokeMethod` với cờ `Qt::QueuedConnection` để chuyển giao tác vụ về luồng giao diện chính (Qt Main GUI Thread).

## 2. Định Nghĩa Kiểu Dữ Liệu Cơ Bản

```c
#ifndef SVM_CORE_H
#define SVM_CORE_H

#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

// Con trỏ đục lỗ đại diện cho ngữ cảnh runtime hoàn chỉnh của ứng dụng
typedef struct SvmContext SvmContext;

// Bộ đệm nhị phân đại diện cho tệp đính kèm, icon, hoặc khối dữ liệu lớn
typedef struct {
    uint8_t *ptr;
    size_t len;
} SvmBuffer;

// Bảng mã lỗi chuẩn C-ABI
typedef enum {
    SVM_OK                    = 0,
    SVM_ERR_INVALID_ARG       = 1,
    SVM_ERR_LOCKED            = 2,
    SVM_ERR_WRONG_PASSWORD    = 3,
    SVM_ERR_IO                = 4,
    SVM_ERR_CRYPTO            = 5,
    SVM_ERR_NOT_FOUND         = 6,
    SVM_ERR_PARSE             = 7,
    SVM_ERR_NETWORK           = 8,
    SVM_ERR_DENIED            = 9,
    SVM_ERR_TIMEOUT           = 10,
    SVM_ERR_CONFLICT          = 11,
    SVM_ERR_UNSUPPORTED       = 12,
    SVM_ERR_PANIC             = 99
} SvmStatus;

// Định danh các sự kiện phát sinh từ Rust Core lên UI
typedef enum {
    SVM_EVENT_VAULT_LOCKED       = 1,
    SVM_EVENT_VAULT_UNLOCKED     = 2,
    SVM_EVENT_ITEMS_CHANGED      = 3,
    SVM_EVENT_PROMPT             = 4,
    SVM_EVENT_PROMPT_CANCELLED   = 5,
    SVM_EVENT_IMPORT_PROGRESS    = 6,
    SVM_EVENT_BRIDGE_STATUS      = 7,
    SVM_EVENT_SSH_STATUS         = 8,
    SVM_EVENT_SHOW_WINDOW        = 9
} SvmEventKind;

// Định nghĩa con trỏ hàm callback sự kiện
typedef void (*SvmEventCallback)(int32_t kind, const char *payload_json, void *user_data);
```

## 3. Danh Mục Chi Tiết Các Hàm C-ABI

### 3.1. Quản Lý Vòng Đời & Bộ Nhớ (Lifecycle & Memory)

```c
// Lấy chuỗi phiên bản của lõi SVM Core
const char *svm_core_version(void);

// Khởi tạo ngữ cảnh SvmContext mới. 
// Tham số data_dir có thể là NULL để sử dụng đường dẫn mặc định của hệ điều hành.
SvmContext *svm_context_new(const char *data_dir);

// Hủy ngữ cảnh và giải phóng toàn bộ runtime tokio, socket listeners và bộ nhớ
void svm_context_free(SvmContext *ctx);

// Đọc thông điệp lỗi chi tiết nhất phát sinh trên luồng hiện tại
const char *svm_last_error(void);

// Đăng ký hàm callback nhận sự kiện từ Rust Core
void svm_set_event_callback(SvmContext *ctx, SvmEventCallback cb, void *user_data);

// Thiết lập các biện pháp gia cố tiến trình (tắt core dump, chặn ptrace)
SvmStatus svm_harden_process(void);

// Giải phóng chuỗi thông thường được cấp phát bởi Rust
void svm_free_string(char *p);

// Giải phóng chuỗi mật mã: ghi đè bằng 0 (zeroize) trước khi giải phóng bộ nhớ
void svm_free_secret(char *p);

// Giải phóng bộ đệm nhị phân SvmBuffer
void svm_free_buffer(SvmBuffer buf);
```
