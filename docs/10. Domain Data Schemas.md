# ĐẶC TẢ LƯỢC ĐỒ DỮ LIỆU MIỀN (DOMAIN DATA SCHEMAS) - SECURE VAULT MANAGER (SVM)

---

## 1. Giới Thiệu & Nguyên Tắc Đồng Bộ Schema

Tài liệu này mô tả chính xác các cấu trúc dữ liệu JSON trao đổi qua FFI C-ABI giữa **Rust Core (`svm-domain`, `svm-vault`, `svm-bridge`, `svm-ssh-agent`, `svm-core`)** và **Desktop Qt6 C++17 (`ui/models/`, `ui/core/core_bridge.cpp`)**.

Mọi thực thể bản ghi trong SVM sử dụng một cấu trúc phẳng **`VaultItem` (32 trường)** dùng chung cho cả **9 danh mục (`Category`)**, đồng thời bộ parser `VaultItem::from_json` hỗ trợ linh hoạt cả khóa `camelCase` (chuẩn đầu ra sang C++/TS) và `snake_case`.

### 2.3. Tóm Tắt Danh Sách (`to_summary_json` trong `svm_items_list`) vs Chi Tiết (`svm_item_get`)

- **`svm_items_list` (`VaultItem::to_summary_json()`):** Trả về **26 trường** metadata và non-secret fields phục vụ hiển thị danh sách thẻ và lọc proxy nhanh (`ItemListModel` / `ItemSortFilterProxy`); **lược bỏ hoàn toàn 6 trường chứa dữ liệu nhạy cảm/dài**: `password`, `totpSecret`, `notes`, `cardNumber`, `cardCvv`, `customFields`.
- **`svm_item_get` (`VaultItem::to_json()`):** Trả về đầy đủ toàn bộ **32 trường** (kèm plaintext khi Vault đang mở khóa) để nạp vào `DetailInspectorView` hoặc trước khi thực hiện cập nhật từng phần (`Toggle Favorite`, `Move to Vault`).
- **`svm_item_reveal_field`:** Giải mã trực tiếp từng trường lẻ (`password` / `payload.password`, `totp` / `totpSecret` / `payload.totp`, `cardNumber` / `payload.card_number`, `cardCvv` / `payload.cvv`, `custom:<id>` hoặc theo `label`) giải phóng qua `svm_free_secret()`.

### 2.4. `CustomField` & `FieldKind` (`svm-domain/src/custom_field.rs`)

Mảng `customFields` áp dụng chung cho **toàn bộ 9 danh mục**:

| Trường | Kiểu | Mô tả |
| :--- | :--- | :--- |
| `id` | `string` | UUID hoặc định danh trường |
| `label` | `string` | Nhãn hiển thị |
| `value` | `string` | Giá trị chuỗi (`"true"`/`"false"` cho `boolean`, `"YYYY-MM-DD"` cho `date`) |
| `kind` | `FieldKind` | `"text"`, `"concealed"`, `"boolean"`, `"date"` |

## 3. Ánh Xạ Trường Theo 9 Danh Mục (`Category` trong `svm-domain/src/category.rs`)

| `Category` | Giá trị JSON (`index`) | Các trường sử dụng chính trong `VaultItem` phẳng |
| :--- | :--- | :--- |
| **`Login`** | `"login"` (`0`) | `username`, `password`, `websiteUrl`, `totpSecret` (`hasTotp`), `notes` |
| **`Passkey`** | `"passkey"` (`1`) | `username`, `websiteUrl`, `password` (PKCS#8 base64), `hasPasskey`, `passkeyCredentialId`, `passkeyRpId`, `passkeyAlgorithm`, `passkeyUserHandle`, `passkeySignCount`, `notes` |
| **`Card`** | `"card"` (`2`) | `username` (Chủ thẻ), `cardNumber`, `cardExpiry`, `cardCvv`, `notes` |
| **`Identity`** | `"identity"` (`3`) | `username`, `websiteUrl`, `notes`, kèm `customFields` |
| **`SecureNote`** | `"secure_note"` (`4`) | `notes` |
| **`SshKey`** | `"ssh_key"` (`5`) | `sshPublicKey`, `sshFingerprint`, `notes` (OpenSSH PEM private key), `isSshLoaded` |
| **`Database`** | `"database"` (`6`) | `dbHost`, `dbPort`, `dbName`, `username`, `password`, `notes` |
| **`Server`** | `"server"` (`7`) | `websiteUrl` (Host/IP), `username`, `password`, `notes` |
| **`Wifi`** | `"wifi"` (`8`) | `wifiSsid`, `wifiSecurity`, `password`, `notes` |

*(Ghi chú về `passkeyAlgorithm`: Lưu mã COSE dạng số nguyên; ví dụ `-7` = `ES256 (ECDSA P-256 / SHA-256) • COSE -7`, `-8` = `EdDSA (Ed25519 / Ed448) • COSE -8`.)*

## 4. Bộ Lọc, Prompt & Cấu Hình Hệ Thống

### 4.1. Bộ Lọc `filter_json` (`svm_items_list` / `svm-vault/src/items.rs`)

```json
{
  "vaultId": "personal",
  "category": "login",
  "query": "github",
  "favoriteOnly": false,
  "includeTrashed": true
}
```

*(Hỗ trợ cả camelCase và snake_case: `vaultId`/`vault_id`, `query`/`search`, `favoriteOnly`/`favorite_only`, `includeTrashed`/`include_trashed` — mặc định `includeTrashed = true` nếu không truyền.)*
