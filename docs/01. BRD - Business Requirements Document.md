# TÀI LIỆU YÊU CẦU NGHIỆP VỤ (BRD) - SECURE VAULT MANAGER (SVM)

---

## 1. Thông Tin Tổng Quan (Executive Summary)

Dự án **Secure Vault Manager (SVM)** hướng tới xây dựng một hệ sinh thái bảo mật định danh và mật khẩu cục bộ (**Local-First, Zero-Knowledge**) với độ tin cậy và hiệu năng tối đa.

Toàn bộ lõi mật mã, logic lưu trữ, quản lý phiên, giao thức liên lạc và tích hợp hệ thống được xây dựng bằng **Rust (cdylib `.so`/`.dylib`/`.dll`)**, đồng thời giao diện máy trạm được viết lại hoàn toàn bằng **C++17 / Qt6 Widgets Native**.

Hệ thống mở rộng toàn diện năng lực quản lý bảo mật hiện đại của một cá nhân và lập trình viên:

1. **Quản lý thông tin đăng nhập & 2FA:** Danh mục `Login` quản lý thông tin tài khoản lớp 1 (Username, Email, Mật khẩu) cùng lớp 2 xác thực hai yếu tố (mã TOTP 2FA RFC 6238), kết hợp các danh mục chuyên biệt: Cards, Secure Notes, Identities, Wi-Fi keys, SSH Keys, Databases, Servers.
2. **Khóa bảo mật Passkey độc lập (FIDO2 / WebAuthn Authenticator):** Danh mục `Passkey` chuyên biệt lưu trữ các cặp khóa bất đối xứng FIDO2 không mật khẩu (passwordless), đóng vai trò là Authenticator cục bộ cho trình duyệt qua Extension, tạo và ký assertion an toàn không phụ thuộc dịch vụ bên thứ ba.
3. **SSH Agent tích hợp:** Cung cấp Unix Domain Socket / Windows Named Pipe chuẩn OpenSSH (`SSH_AUTH_SOCK`), bảo vệ SSH Private Keys trực tiếp trong RAM và hỗ trợ phê duyệt trước khi ký (`Approval Prompt`).
4. **Kênh kết nối Extension đa tầng:** Ưu tiên chuẩn **Native Messaging Host (JSON framing)** tiêu chuẩn bảo mật của Chromium & Firefox; duy trì kênh Loopback HTTP Server an toàn (tắt mặc định, kích hoạt qua cấu hình) cho môi trường sandbox cô lập như Snap/Flatpak.
5. **Đính kèm tệp mật (Secure File Attachments) & Lịch sử phiên bản (Item History):** Lưu trữ các file chứng chỉ, keyfiles, file cấu hình mã hóa streaming AEAD chunking và phục hồi lịch sử sửa đổi.

## 2. Bối Cảnh Thực Tế & Mục Tiêu Chiến Lược

### 2.1. Phân Tích Nỗi Đau Thực Tế (Pain Points)

- **Rủi ro rò rỉ dữ liệu đám mây (Cloud Data Breaches):** Các vụ rò rỉ cơ sở dữ liệu vault tập trung (LastPass, Okta...) chứng minh mô hình lưu trữ vault trên máy chủ nhà cung cấp tiềm ẩn rủi ro phá hủy uy tín và dữ liệu cá nhân.
- **Tiêu tốn tài nguyên của Web-based Desktop Apps (Electron / Webview2):** Các ứng dụng bọc nền web tiêu tốn hàng trăm MB RAM, khởi động chậm, rủi ro tấn công XSS trong môi trường render DOM và khó quản lý bộ nhớ an toàn (zeroize, mlock).
- **Trải nghiệm rời rạc đối với Developer & Sysadmin:** Việc sao chép thủ công SSH Private Keys hoặc mật khẩu cơ sở dữ liệu làm tăng nguy cơ rò rỉ qua clipboard, thiếu cơ chế SSH Agent tích hợp với khóa tự động.
- **Sự chuyển dịch sang Passkey (Passwordless WebAuthn):** Các website dần thay thế mật khẩu bằng Passkey, đòi hỏi trình quản lý mật khẩu phải có khả năng hoạt động như một WebAuthn Authenticator độc lập và an toàn.
- **Hạn chế của Linux Snap/Flatpak đối với Native Messaging Host:** Môi trường sandbox nghiêm ngặt ngăn cản trình duyệt spawn trực tiếp binary native host ngoài container, gây lỗi kết nối trên Ubuntu/Fedora nếu không có cơ chế fallback.

### 2.2. Mục Tiêu Chiến Lược (Strategic Objectives)

- **Local-First & Zero-Knowledge Tuyệt Đối:** Dữ liệu hoàn toàn nằm dưới quyền kiểm soát của người dùng. Master Password không bao giờ được ghi đĩa hay gửi qua mạng.
- **Độ Trễ Siêu Thấp & Siêu Nhẹ (Native Performance):** Core Rust tối ưu hiệu năng tính toán mật mã; Qt6 Widgets tối ưu hiển thị, khởi động dưới `150ms` (cold start), RAM tiêu thụ dưới `40MB` ở chế độ thu nhỏ khay hệ thống.
- **Khóa Bộ Nhớ Vật Lý Đa Tầng (Multi-tiered Memory Safety):** Sử dụng `mlock`/`VirtualLock` cho các khóa nhạy cảm (KEK, DEK, SSH/Passkey private keys), tắt core dump toàn tiến trình (`PR_SET_DUMPABLE = 0`), zeroize vùng nhớ khi giải phóng.
- **Tính Tương Thích Rộng Rãi:** Hỗ trợ mọi hệ điều hành phổ biến (Linux X11/Wayland, Windows 10/11, macOS) và mọi trình duyệt chính (Chrome, Brave, Edge, Firefox).

## 3. Phạm Vi Dự Án (Project Scope)

### 3.1. Phân Hệ Desktop Native (Qt6 + Rust cdylib)

- **Rust Core Engine (`libsvm_core.so`):**
  - Quản lý toàn bộ cấu trúc dữ liệu miền (`svm-domain`), dẫn xuất khóa KDF Argon2id (`svm-crypto`), mã hóa Envelope (Master Key -> KEK -> DEK).
  - Quản lý kho lưu trữ tệp `.svm` nguyên tử kèm snapshot backup và mã hóa tệp đính kèm streaming chunking (`svm-storage`).
  - Dịch vụ xác thực FIDO2 / Passkeys (`svm-webauthn`).
  - OpenSSH Agent Socket Daemon (`svm-ssh-agent`).
  - Lõi tính toán mã OTP RFC 6238 / RFC 4226 và giải mã QR code (`svm-totp`).
  - Kênh giao tiếp IPC Listener cục bộ và Native Messaging Host (`svm-ipc`, `svm-native-host`, `svm-bridge`).
  - Trình phân tích / nhập / xuất dữ liệu đa định dạng 1PUX, Bitwarden, KeePass XML, CSV, SVM (`svm-transfer`).
  - Prompt Broker: Cơ chế điều phối yêu cầu tương tác hai chiều (Consent/Approval) từ Core sang UI.
- **Qt6 Native UI:**
  - Giao diện người dùng Frameless hiện đại hỗ trợ Dark/Light Theme và đa ngôn ngữ (EN, VI).
  - Khay hệ thống (System Tray) song ngữ, cơ chế chạy một phiên duy nhất (`SingleInstance`).
  - Màn hình Onboarding, Vault Selection, Unlock, Dashboard danh mục & chi tiết, Settings.
  - Dialog phê duyệt: `PasskeyConsentDialog`, `SshApprovalDialog`, `SaveCredentialDialog`, `PairingDialog`.
  - Giám sát thời gian rảnh hệ thống (`IdleMonitor`) chống rò rỉ mật khẩu và tự động khóa.
  - Bảo vệ Clipboard (`ClipboardGuard`) tự xóa sau N giây và gắn cờ tránh lịch sử clipboard OS.

### 3.2. Phân Hệ Browser Extension (Manifest V3)

- Hỗ trợ Chrome/Chromium, Brave, Edge, Vivaldi và Mozilla Firefox.
- Giao tiếp ưu tiên qua **Native Messaging Host**; fallback HTTP Loopback AES-256-GCM (nếu người dùng bật thủ công).
- Tự động nhận diện form đăng nhập, smart in-field badge gợi ý điền thông tin tự động an toàn.
- Hook API `navigator.credentials.create()` và `navigator.credentials.get()` trong MAIN world để xử lý Passkey mượt mà.
- Bắt sự kiện nộp biểu mẫu để nhắc lưu tài khoản mới (`Save Prompt`).
- Quét mã QR 2FA trên trang để trích xuất secret TOTP.

### 3.3. Ngoài Phạm Vi (Out-of-Scope)

- **Đồng bộ hóa đám mây (Cloud Sync):** Không triển khai máy chủ trung gian. Người dùng có thể sao lưu thủ công hoặc đặt thư mục vault trên thư mục đồng bộ tệp riêng (Syncthing/Nextcloud).
- **Chia sẻ nhóm / Tổ chức (Enterprise Team Management):** Không hỗ trợ kiểm soát truy cập đa người dùng trong phiên bản cá nhân.
- **Ứng dụng di động (Mobile Apps):** Phiên bản v1 tập trung toàn diện cho môi trường máy trạm Desktop (Linux, Windows, macOS) và Browser Extension; ứng dụng di động (iOS/Android) nằm ngoài phạm vi phiên bản này.

## 4. Yêu Cầu Nghiệp Vụ Chi Tiết (Detailed Business Requirements)

### 4.1. Quản Lý Kho & Phân Loại Dữ Liệu

- **BR-VAULT-01:** Hỗ trợ đa kho lưu trữ (Multi-vault). Mỗi vault là một kho dữ liệu độc lập với Master Password riêng biệt. Tại một thời điểm, hệ thống duy trì tối đa 01 phiên Vault mở khóa hoạt động (Active Vault Session); các dịch vụ nền (SSH Agent daemon, Extension Bridge) phục vụ dữ liệu từ kho đang mở này. Khi chuyển đổi kho, kho hiện tại sẽ được tự động khóa an toàn.
- **BR-VAULT-02:** Hỗ trợ 9 danh mục dữ liệu chuyên biệt: `Login` (Mật khẩu & mã xác thực TOTP 2FA), `Passkey` (Khóa xác thực FIDO2/WebAuthn), `Card` (Thẻ thanh toán), `SecureNote` (Ghi chú bảo mật), `Identity` (Hồ sơ định danh), `Wifi` (Mật khẩu Wi-Fi), `SshKey` (Khóa SSH), `Database` (Cơ sở dữ liệu), `Server` (Máy chủ).
- **BR-VAULT-03:** Hỗ trợ tệp đính kèm bí mật (Attachments) cho mỗi item với kích thước tối đa 50MB/file.
- **BR-VAULT-04:** Hỗ trợ lịch sử phiên bản (Revision History) tối đa 20 bản ghi sửa đổi gần nhất cho mỗi item.
- **BR-VAULT-05:** Hỗ trợ mở rộng Trường Tùy Biến (Custom Fields) không giới hạn trên toàn bộ các danh mục. Cho phép người dùng bổ sung các trường thuộc 4 kiểu dữ liệu: `text` (văn bản thường), `concealed` (bảo mật/ẩn tự zeroize), `boolean` (bật/tắt), và `date` (ngày tháng).
- **BR-VAULT-06:** Hỗ trợ Khóa Khôi Phục Khẩn Cấp (Recovery Key 24 ký tự định dạng `XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`) sinh tự động khi khởi tạo kho, cho phép mở khóa và đặt lại Master Password mà không làm mất dữ liệu (nhờ cơ chế bọc kép DEK trong Header).
- **BR-VAULT-07:** Tích hợp trung tâm kiểm toán bảo mật **Watchtower** tự động phân loại và cảnh báo các mật khẩu yếu (`passwordStrengthScore < 50`), mật khẩu dùng lại trên nhiều dịch vụ, tài khoản chưa bật 2FA (TOTP), và các mục sắp hết hạn.

### 4.2. Mật Mã Học & An Toàn Bộ Nhớ

- **BR-CRYPTO-01:** Cơ chế Zero-Knowledge tuyệt đối. Khóa dẫn xuất KEK bằng Argon2id (Memory: 64MiB, Iterations: 3, Parallelism: 4).
- **BR-CRYPTO-02:** Mô hình Envelope Encryption. Khóa DEK (32 bytes ngẫu nhiên) được mã hóa bằng KEK. Khi đổi Master Password, chỉ cần tái mã hóa DEK mà không cần giải mã và mã hóa lại toàn bộ items/blobs.
- **BR-CRYPTO-03:** Các khóa giải mã nhạy cảm trong RAM phải được bảo vệ bằng `mlock`/`VirtualLock` và tự động zeroize khi thu hồi.
- **BR-CRYPTO-04:** Tiến trình hệ thống phải vô hiệu hóa core dump và ngăn chặn debugger không có quyền can thiệp.

### 4.3. Passkey & WebAuthn

- **BR-PASSKEY-01:** Hỗ trợ các thuật toán ký số chuẩn FIDO2/WebAuthn: `ES256` (ECDSA P-256 với SHA-256, COSE `-7`) và `EdDSA` (Ed25519, COSE `-8`).
- **BR-PASSKEY-02:** Extension tự động xác thực tên miền RP (Relying Party) dựa trên `sender.url` (tuyệt đối không tin cậy dữ liệu do web script gửi).
- **BR-PASSKEY-03:** Mỗi lần tạo hoặc xác thực Passkey phải hiển thị hộp thoại xin phép (`PasskeyConsentDialog`) trên Desktop App để người dùng phê duyệt.

### 4.4. SSH Agent

- **BR-SSH-01:** Cung cấp Unix Domain Socket hoặc Named Pipe chuẩn OpenSSH protocol.
- **BR-SSH-02:** Tự động nạp SSH Keys khi mở khóa Vault và tự động giải phóng toàn bộ keys khi khóa Vault.
- **BR-SSH-03:** Phê duyệt trước khi ký (`SSH Approval Prompt`): Khi một tiến trình gửi `SSH2_AGENTC_SIGN_REQUEST`, hiển thị tên tiến trình (PID) và thông tin key để người dùng chấp thuận (hỗ trợ ghi nhớ phê duyệt trong 10 phút).

### 4.5. Kết Nối Trình Duyệt (Browser Integration)

- **BR-EXT-01:** Giao tiếp chính qua Native Messaging Host chuẩn JSON framing.
- **BR-EXT-02:** Khóa ghép nối X25519 + HKDF với mã xác thực 6 số (Pairing Code) ngăn chặn kết nối trái phép.
- **BR-EXT-03:** Hỗ trợ tùy chọn kích hoạt HTTP Loopback Server (`127.0.0.1:12519`) có cơ chế chống DNS Rebinding và giới hạn CORS chỉ cho extension đã ghép nối.

## 5. Yêu Cầu Phi Chức Năng (Non-Functional Requirements)

### 5.1. Hiệu Năng & Tài Nguyên

- **NFR-PERF-01:** Thời gian khởi động ứng dụng tới màn hình chính (cold start) < `150ms`.
- **NFR-PERF-02:** Bộ nhớ RAM tiêu thụ khi khóa/chạy nền ở khay hệ thống < `40MB`.
- **NFR-PERF-03:** Thời gian phản hồi truy vấn tìm kiếm credential cho Extension < `5ms`.
- **NFR-PERF-04:** Giải mã Vault khi mở khóa (Argon2id KDF) trong khoảng `150ms - 400ms` trên phần cứng tiêu chuẩn.

### 5.2. An Toàn & Bảo Mật

- **NFR-SEC-01:** Không ghi bất kỳ khóa bí mật nào ra tệp hoán đổi (Swap/Paging file).
- **NFR-SEC-02:** Toàn bộ API FFI C-ABI phải bọc trong `catch_unwind` bảo đảm không bao giờ gây lỗi Panic xuyên qua ranh giới Shared Library.
- **NFR-SEC-03:** Xóa dữ liệu nhạy cảm khỏi Clipboard sau khoảng thời gian mặc định 30 giây.

### 5.3. Khả Năng Tương Thích Nền Tảng & Trải Nghiệm Người Dùng (UX)

- **NFR-COMPAT-01:** Hệ điều hành: Linux (Ubuntu 22.04+, Debian 12+, Fedora 38+, Arch - hỗ trợ X11 & Wayland), Windows 10/11 64-bit, macOS 12+ (Intel & Apple Silicon).
- **NFR-COMPAT-02:** Trình duyệt: Google Chrome 88+, Mozilla Firefox 109+, Microsoft Edge, Brave, Vivaldi.
- **NFR-UX-01:** Giao diện tối giản, chuyên nghiệp theo bảng màu Catppuccin Mocha (Dark) / Latte (Light); tuyệt đối không sử dụng biểu tượng cảm xúc (emoji) và không phô bày các thuật ngữ kỹ thuật mật mã phức tạp trên giao diện người dùng cuối.
- **NFR-UX-02:** Mọi hộp thoại (Dialog) không viền đều hỗ trợ kéo thả di chuyển mượt mà (`DialogDragHelper`) và áp dụng cơ chế khóa tương tác cửa sổ chính (Modal) kèm hiệu ứng cảnh báo trực quan khi người dùng bấm ra ngoài hộp thoại đang mở.
